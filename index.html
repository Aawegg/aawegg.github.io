I'm an applied AI engineer who's a little obsessed with whether AI systems actually work. At Turing I build agent benchmarks in Harbor format (terminal, multi-agent and enterprise-tool tasks with deterministic verifiers), and I led an evaluation pod on Terminal Bench, OS Bench and SWE-Bench.

Outside of that I build my own things: an RL agent for a Kaggle simulation competition (provisional silver), hand-written ARM NEON quantization kernels, an LLM judge calibrated against a human grader, and a multimodal RAG app. Proof beats vibes.

01

Kaggriculture (Kaggle)

An RL agent for a farming simulation competition: provisional silver, around the top 1% of 10,246 teams. I built a C++ replica of the game engine (move-for-move parity, ~1.5M games an hour) and trained a late-game policy with PPO that added about $400 a game on 2,400 fresh games. Biggest lesson: a behaviour-cloned copy of the #1 player was 81% accurate offline and still lost live.

02

NibbleCore

From-scratch 4-bit (Q4_0) quantization kernels in C++ with ARM NEON SIMD and a GGUF loader, benchmarked on real SmolLM2 weights: 3.4x faster dequantization than llama.cpp's scalar reference and a 4.8x faster SDOT dot product, with bit-identical output.

C++ARM NEONGGUFllama.cpp
Code
03

priorityjudge

A multi-pass LLM judge for plans and PRDs (extractor, five per-criterion scorers, a deterministic citation verifier, synthesizer). On a 6-plan calibration set: 9887/10000, perfect rank correlation with the human grader, 96.5% citation precision and 99.6% test-retest stability. About 30 CI tests keep it honest.
